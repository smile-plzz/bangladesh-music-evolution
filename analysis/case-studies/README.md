# Sound Evolution Case Studies

Five case studies developed against the project's own datasets. Each one takes
an act or strand through the five analytical dimensions in the research
proposal — musical, cultural, listener, concert, industry — and, where the data
supports it, states its position in the Bangladesh Music Preference Network
using the figures computed in `analysis/outputs/`.

| Study | Strand | Why this case |
|---|---|---|
| [`warfaze.md`](./warfaze.md) | Heavy Metal | The legitimation arc: covers → original Bangla metal → state honour |
| [`artcell.md`](./artcell.md) | Progressive Rock/Metal | The clearest documented case of technical global form localised through Bangla literary writing |
| [`meghdol.md`](./meghdol.md) | Alternative/Indie | Literary indie, a nine-year hiatus, and late entry to the festival network |
| [`hip-hop-lineage.md`](./hip-hop-lineage.md) | Hip-Hop/Rap | A strand with a 30-year documented lineage and almost no presence in the live network |
| [`folk-fusion-platforms.md`](./folk-fusion-platforms.md) | Folk & Folk Fusion | How platforms and festivals, not labels, carry folk material into the mainstream |

**A standing caveat.** No audio-feature extraction was possible in this project
(no streaming API credentials; see `docs/roadmap.md`). Every claim about tempo,
production or arrangement here rests on documented statements, contemporaneous
reviews and discographic sequence — not on measured signal. Where a claim would
need audio analysis to settle, it is marked as such rather than asserted.
