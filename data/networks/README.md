# Bangladesh Music Preference Network (BMPN)

Graph data connecting artists, genres, concerts, and (eventually) listener communities.

## Status: Prototype

`bmpn-prototype.json` is auto-generated by `analysis/scripts/build_bmpn_prototype.py` from concert co-billing data (`data/concerts/*.json`). It is a **first-pass proxy**, not a validated preference network:

- **Nodes**: all 52 catalogued artists (`data/artists/`)
- **Edges**: pairs of artists who shared a concert bill, weighted by number of shared events, with `shared_events` listing the underlying concert IDs — currently **38 edges** from 12 documented concerts (including the RockNation 2013-14 festival series)
- **Coverage gap**: 34 of 52 nodes are currently isolated (no edges). This will improve as the concert database (`data/concerts/`) grows toward its ≥500-event target.

`bmpn-clusters.json` is auto-generated by `analysis/scripts/build_bmpn_clusters.py` and holds a connected-components grouping of the graph above — a minimal, honest first pass at listener-ecosystem structure. As of the RockNation additions there is one 13-artist cluster (metal/alt-rock scene: Artcell, Warfaze, Cryptic Fate, Mechanix, Aurthohin, Karnival, Chirkutt, Nemesis, Shunno, Arbovirus, Lalon Band, Renaissance, Maqsood O' Dhaka) plus a 2-artist cluster (Indalo, Powersurge) and 37 isolated nodes.

## Regenerating

```
python3 analysis/scripts/build_bmpn_prototype.py
python3 analysis/scripts/build_bmpn_clusters.py
```

Re-run both after adding new concert or artist records; both scripts are idempotent and overwrite their output files.

## Planned Extensions

1. **Streaming/playlist co-occurrence** — related-artist and playlist-adjacency signals from Spotify/YouTube (pending public data collection; see `docs/roadmap.md`).
2. **Social listening / community discussion** — shared-fandom signals from social media sampling.
3. **Modularity-based community detection** — connected components (`bmpn-clusters.json`) are a placeholder; once the graph has sufficient density, apply standard algorithms (e.g., Louvain) to identify finer-grained listener-ecosystem clusters, feeding into the BMEM's "Listener Preference Networks" dimension.
4. **Genre-weighted edges** — distinguish co-billing within a single genre scene (e.g., the metal/alt-rock cluster already visible) from cross-genre pairings (e.g., the Coke Studio Bangla folk-hip-hop pairing).
