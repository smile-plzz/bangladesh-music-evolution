# Timelines

This directory will contain the Bangladesh Music Evolution Timeline and related chronological materials.

## Planned Deliverable

**Bangladesh Music Evolution Timeline (1971–Present)** covering:

- Major genre emergences and shifts
- Landmark albums and artists
- Technological and industry milestones (cassette, CD, FM, TV channels, YouTube, Spotify, etc.)
- Significant concerts and festivals
- Cultural and political contexts that shaped musical expression

## File Structure (planned)

- `master-timeline.md` — narrative + year-by-year overview
- `genre-emergence.csv` — structured data for visualization
- `industry-milestones.md`
- `key-events.json` — machine-readable events for network/timeline tools

Data will be triangulated from historical sources, discographies, news archives, and platform metadata.
